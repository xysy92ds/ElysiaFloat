# 🌐 浏览器用户脚本 · 爱莉希雅网页助手

> ⚠️ **这里是给浏览器用的，不是安卓 App。**
> 这是整个项目**最早的版本**，功能只覆盖基础聊天，定位是"轻量尝鲜版"。

想读屏、屏幕翻译、识图、长期记忆、后台放歌 —— 请装 [`../android/`](../android/) 里的 **App 版**。

---

## 它能做什么 / 不能做什么

✅ **能**

- 在当前网页里注入一个粉色悬浮球 + 对话面板
- 和 AI 聊天（同样的爱莉希雅人设、同样的服务商预设）
- 翻译**当前网页**（免费微软引擎 / AI 引擎，可切换仅译文、双语对照）
- 朗读回复（系统 TTS / OpenAI 兼容接口）
- 放歌（GD Studio / Meting 双源搜索播放）
- 导入导出配置

❌ **不能**（这些**只有 App 版有**）

| 做不到的事 | 为什么 |
|---|---|
| 读别的 App 的界面 | 浏览器沙箱只能看到当前网页的 DOM |
| 读当前网页的"可见区域"以外的东西 | 同上，只能拿到 `document.body.innerText` |
| 屏幕翻译 / 把译文贴回屏幕 | 没有坐标系统，翻译只作用于网页文字 |
| 截屏、识图 | 浏览器页面拿不到系统级截屏 |
| 真正的系统悬浮窗 | 只是一个网页内的 `div`，切标签页就没了 |
| 长期记忆库 | 没实现（App 版有完整的分类记忆系统） |
| 后台上传文件 | 没实现 |
| 关掉页面还继续放歌 | 页面一关，播放器就停了 |

**一句话**：用户脚本 = 在**网页里**加了个 AI 助手；App = 在**整台手机上**装了个 AI 助手。

保留它的意义是：**不用装 App、不用开任何权限，在电脑浏览器上打开就能用**，适合先看看这个助手长什么样、说话什么风格。

## 安装

1. 浏览器安装用户脚本管理器（任选其一）
   - Tampermonkey（油猴）
   - Violentmonkey
   - ScriptCat
2. 打开管理器 → **新建脚本**
3. 把 `.user.js` 的内容**整个复制粘贴**进去
4. `Ctrl/Cmd + S` 保存
5. 刷新任意网页，右下角出现粉色悬浮球即成功

手机上也能用：Kiwi Browser / Firefox 移动版 + Tampermonkey。

## 需要授予的权限

| 指令 | 用途 |
|---|---|
| `GM_setValue` / `GM_getValue` | 保存 API Key、模型、头像等配置 |
| `GM_xmlhttpRequest` | 跨域请求 AI 接口、翻译接口、音乐接口 |

`@connect` 里列出的域名是脚本会主动访问的接口，包括：
- `edge.microsoft.com` — 翻译
- `app.everyapi.ai` — 默认 AI 接口
- `music-api.gdstudio.xyz` 等 — 音乐搜索
- `music.163.com` — 网易云

如果你换了别的 AI 服务商，记得在脚本头部 `@connect` 里补上它的域名，否则会被管理器拦截。

## 和 App 版的关系

两者界面长得像、人设一样，但**完全是两套独立代码**：

| | 用户脚本 | App |
|---|---|---|
| 环境 | 浏览器 | 安卓系统 |
| 存储 | `GM_setValue` | SharedPreferences |
| 网络 | `GM_xmlhttpRequest` | 原生 `HttpURLConnection` |
| 界面 | 注入 DOM | WebView 加载 `assets/index.html` |
| 系统能力 | 无 | 无障碍读屏 / 截屏 / 悬浮窗 / 前台服务 |

所以：

- ❌ `.user.js` **不能**当 APK 装
- ❌ APK 里的 `index.html` **也不能**直接当用户脚本用（它依赖 `Android.*` / `Perm.*` 桥，在浏览器里不存在）

App 版源码见 [`../android/`](../android/)，项目总览见 [根目录 README](../README.md)。
