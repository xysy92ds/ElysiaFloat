# 讨论结论：0.6.2 插件系统、远程市场和 GitHub 同步

日期：2026-10-06
状态：本地实现完成；远程推送等待新凭据。

## 确认事项

- 版本提升为 `0.6.2` / versionCode `12`。
- 插件系统继续采用 Manifest v1、插件级/工具级权限、隔离 JS 沙箱和 Host API。
- 远程插件市场先实现用户主动触发的 HTTPS 只读索引同步，不自动安装或执行远程代码。
- 远程安装前必须校验索引、Manifest、插件 ID、版本和 SHA-256；哈希匹配不等于代码安全。
- 插件页面展示来源、信任标签和审核状态；这些字段不能替代用户审查。
- 插件危险权限默认未授权；旧版缺少授权状态的插件也按未授权处理。
- 插件生命周期使用宿主状态记录和有限审计记录，不执行安装时隐藏的生命周期脚本。
- 主要文档描述当前应用状态；0.6.1-agent 和 0.6.2 的历史记录分别存放在 `docs/history/`。
- GitHub 作为开源发布平台；用户已请求同步仓库。

## 安全事项

用户在聊天中提供的 GitHub Token 已视为暴露凭据，不使用、不保存、不写入远程 URL、Git 配置、日志或 APK。推送前必须撤销旧 Token，并使用新的最小权限 Fine-grained Token，通过环境变量或本机 credential helper 提供。
