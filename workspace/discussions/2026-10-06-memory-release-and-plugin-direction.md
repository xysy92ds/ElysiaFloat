# 讨论结果：记忆合并规则、0.6.1 发布准备与插件开放性

日期：2026-10-06
状态：本地实现和构建已完成；远程上传仍然暂停。

## 用户反馈与确认

- 工作区内读写已可用。
- 用户还需要访问手机公共存储中、工作区以外的文件；工作区继续作为 Agent 的默认受控目录，工作区外也允许修改，但每次修改前必须弹窗确认。
- QQ 应用启动已经可用。
- 输入法兜底尚未进行真机测试。
- 记忆总结不能默认修改既有记忆。
- 记忆处理规则调整为：以新增为默认；类别相同仍允许新增；只有正文高度相似并明确属于同一事实时才合并；合并必须保留原文，并将新内容追加到原文后，不得缩短。
- 当前目标是完成 `0.6.1-agent` 的发布准备；上传动作等待用户提供凭据，不在没有凭据时执行。
- 发布文档需要重新整理，术语采用技术/学术表达，减少拟人化和模型口吻。

- 配置、状态、日志、版本和迁移
- 本地插件、远程插件和可信来源
- 插件之间的组合与事件机制
