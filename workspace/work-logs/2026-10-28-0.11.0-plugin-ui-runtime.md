# 2026-10-28 · 0.11.0 插件 UI 运行时（E4）

## 目标

让插件用通用原语组合出宿主没写过的界面与行为：挂载点、样式白名单、主题包、会话类型引擎、
每轮模板与交互、设置扩展、卸载清理、开发者工具包，并用三个验收插件证明宿主零改动。

## 已完成

### E4-001 挂载点注册表

- `entry` surface 支持 `mount` + `sort` + `when`（`always` / `chat` / `session`）。
- 聊天页实际渲染：`chat.header` → `#plug-mount-head`、`chat.footer` → `#plug-mount-foot`、
  `chat.composer.before` → `#plug-mount-composer`；助手消息后追加 `chat.message.after`。
- 设置页渲染 `settings.section`，点击/配置事件统一走 `plugHandleUiAction`。
- 启停/安装/删除后自动刷新挂载点；切换聊天视图与启动完成时恢复主题。

### E4-002 通用样式白名单

- 新增 `plugNormalizeStyle`：只接受 `bg/color/radius/padding/margin/fontSize/fontWeight/opacity/shadow/image`。
- 正则以白名单校验：十六进制/rgb(a)/透明/currentColor、px/%/rem/em 长度、字重、投影；
  任意 CSS、`expression()`、`url(javascript:)` 一律丢弃。
- `plugStyleAttr` 生成转义后的 `style`；图片仅接受 HTTPS 或 `data:image/*;base64`。

### E4-003 主题包

- `theme` surface：`tokens`（样式令牌）+ `background` + `dark`。
- 作用域：全局与单会话（按任务 ID）隔离；`theme.apply` / `theme.reset` 为真实动作；
  应用后立即预览，`plugThemeRestore` 在启动/切回聊天时恢复。
- 对比度审计：前景/背景十六进制亮度比 < 3 时记 `theme_contrast` 审计，不阻断应用。

### E4-004/005/006 会话类型引擎、模板与每轮交互

- `sessionType`：`stateSchema` 默认值初始化、`opening` 开场、`renderer` 命名模板、
  `endWhen`（`path ==/!=/>/</>=/<= value`，数字优先）、`deletable`、`vars`。
- 每轮回复后由 `plugSessionAfterReply` 渲染模板、推进 `round`、检查结束条件；
  结束时标记 `ended`、发 `session.delete` 事件并追加结束提示。
- `choice` 组件保留「自定义输入…」按钮，插件不能锁死输入框。

### E4-007 设置扩展

- 设置页末尾按需渲染「插件设置」分区（`settings.section` 挂载）。
- 复用组件树、动作与配置 Schema；点击事件进入宿主校验。

### E4-008 卸载清理

- 卸载时清理：私有状态、配置、定时任务、主题（全局与所有会话）、插件创建的会话任务；
  当前任务被清理时切回聊天任务并恢复上下文。
- 删除确认提示会话数量与清理范围。

### E4-009 开发者工具包

- `tools/plugin-validate.js`：清单结构、surface 被接受情况、组件/动作类型、主题对比度；
  支持单文件或目录，退出码可接 CI。
- `plugin-examples/`：`template.json`、`theme-aurora.json`、`dating-game.json`、`pomodoro.json` + README。

### 验收插件（E4 出口）

1. 主题插件 `theme-aurora.json`：两个主题包 + 预览页 + 设置分区，可应用/重置。
2. 恋爱游戏 `dating-game.json`：专属会话、每轮模板、状态保存、`affinity >= 3` 结束、卸载清理。
3. 番茄钟 `pomodoro.json`：聊天头部计时器、专注会话、统计页、定时任务，全部宿主原语组合。
