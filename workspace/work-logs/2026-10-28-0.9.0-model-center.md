## 关键实现

### 密钥与模型中心

- `SecretsVault.kt`：AES-256-GCM + AndroidKeyStore，`SharedPreferences("elly_secrets")` 只存密文；Keystore 失败不回退明文。
- `JsBridge.kt`：暴露 `secretPut/secretGet/secretHas/secretDelete/secretList`。
- `00-compat.js`：`sSet` 是唯一持久化收口点，自动剔除 `apiKey/visionKey/ttsApiKey/vecKey` 并先写密钥仓。
- `02b-providers.js`：`providerMigrate/SyncLegacy/Resolve/Apply/Upsert/Remove/Bind`；`chatReq` 仍读旧扁平字段，不侵入请求层。
- `02c-usage.js`：按天统计 calls/token，`0 = 不限`；超限时 `chatReq` 直接拦下并给出可操作提示。
- `14-update.js`：五分组（AI 与模型 / 外观 / 权限 / 工作区 / 高级）+ 模型中心卡片 + 用量卡片。

### 体验

- 视图栈：`VIEW_STACK = ['chat']`，启动固定 `showView('chat')`，系统返回与页面返回按钮都逐层退回。
- 自动确认：仅 `device` + `external_write` 两类；密码框、发送、支付、卸载、删除、Root/Termux 仍逐次确认；开启/关闭写 `auto_confirm_on/off` 审计。
- 运行状态条：普通 flex 子项，位于输入区上方；`setInterval` 每秒刷新心跳秒数，停止键复用 `send()` 的停止路径。
