# 工作记录：音乐系统第二阶段 UI/队列/缓存面板完成

日期：2026-10-16
状态：本地实现、smoke 和 Debug 构建完成；真机验证待进行

## 用户体验问题修复

根据用户反馈，音乐列表不再在每首歌曲后面显示加号、缓存或收藏按钮，避免歌曲名被挤压。

歌曲列表现在：

- 单击直接播放；
- 播放成功自动加入播放队列；
- 长按或右键打开小型操作菜单；
- 菜单提供播放、加入队列、收藏/取消收藏、缓存/删除缓存；
- 历史、缓存和队列页面中的删除操作也统一放入长按菜单；
- 收藏不再依赖列表末尾的按钮，歌曲标题有更多空间。

## 音乐页面

新增/完善：

- 搜索；
- 收藏；
- 播放历史；
- 播放队列；
- 缓存歌曲专属面板；
- 缓存歌曲可以直接点击播放；
- 缓存单曲删除；
- 历史记录删除；
- 队列项目移除；
- 全部清理缓存只在“缓存”页显示；
- 缓存数量和路径信息只在“缓存”页显示；
- 加载更多只在搜索页且确实还有下一页时显示；
- `[hidden]` 强制隐藏规则，避免加载更多按钮在其它页面占据空间。

## 主题和设置

音乐设置继续位于设置页“音乐功能”分区，新增：

- 自动缓存播放歌曲；
- 保存播放历史；
- 历史记录上限；
- 是否显示来源信息；
- 来源目录和 Meting 实例保持可配置。

音乐页面颜色使用 `--c1`、`--c2`、`--card`、`--text`、`--muted` 等全局主题变量，跟随“个性化与聊天风格 → 外观”的主颜色，不再固定使用独立粉色。
