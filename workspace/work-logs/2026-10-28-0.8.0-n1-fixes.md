## 现象与根因

### I-055 粘贴、复制「依旧不行」

0.7.2 的 I-048 只修了「菜单项被 touchend 提前隐藏」，真机上还有两个必现问题：

1. `bindCtxMenu` 的 `touchmove` **无条件取消**长按，手指抖动 1~3px 就作废 550ms 计时器，菜单根本不出现；
2. 长按弹出菜单后抬手，`touchend` 执行「无选中文本就隐藏」，菜单一闪就没；
3. 输入框弹菜单前没有 `focus()`，Android 10+ 窗口无焦点时 `getClipboard()` 返回空。

修改 `android/app/src/main/assets/src/scripts/01-ui-dialog.js`：

- `touchmove` 改为 14px 容差（`MOVE_TOLERANCE`）；
- 新增 `CTX_HOLD_OPEN`，忽略长按那一次抬手，`hideCtxMenu()` 一并复位；
- `openCtxFor` 输入框分支先 `target.focus()`。

### I-056 横屏退出后悬浮窗跑出屏幕

`showWebView()` 用隐藏那一刻的 `savedRect` 直接恢复，没有重新夹持；横屏隐藏 → 竖屏恢复时带着横屏坐标，窗口落在屏幕外。

修改 `android/app/src/main/java/com/elly/float/FloatService.kt`：

- `showWebView()` 恢复 `savedRect` 时先 `clampRect`；
- `onConfigurationChanged` 把 `savedRect` 重新夹持，并在 120ms / 400ms 补两次 `clampCurrentWindow()`（旋转后 `displayMetrics` 可能延迟稳定）；
- 新增 `clampCurrentWindow()`，隐藏态（`winHidden`）直接跳过，避免把隐藏窗口拉回屏幕。

### I-057 音乐指令无法调用，AI 只输出指令文本

`buildTools()` 默认确实包含 `search_and_play_music` / `music_control`（smoke 已守护），不是工具没定义。真因是 **`toolsBroken` 被永久毒化**：`chatReqTools()` 兜底条件写成 `/tool|function|400/i`，任意一次 400（上下文超长、参数异常等）都会把会话永久切成无工具对话，之后模型只能把调用写成正文。

修改：

- `11-plugin-engine.js`：兜底只认真正的工具不支持文案（`toolUnsupported` 正则）；新增 `resetToolFallback()`；
- `12-send-quick.js`：`send()` 与 `handleQuickAction()` 每轮开始调用 `resetToolFallback()`。

### I-058 设备任务最后一步「发送」不会

只有 `click_text('发送')` 一条路，且发送按钮常被软键盘遮挡；`findNode` 还是**全等匹配**，控件文字稍有差异就找不到。

修改：

- `EllyAccessibilityService.kt`：抽出 `findFocusedEditable()`；新增 `submitCurrentInput()`，先 `ACTION_IME_ENTER`，再不支持时按 发送/Send/提交 找可点击节点（无障碍 `ACTION_CLICK` 不受遮挡影响）；
- `PermissionBridge.kt`：`agentKey(enter|send)` 接到 `submitCurrentInput()`；
- `10-music.js`：`press_key` schema 增加 `enter`；`press_key enter` 与 `click_text` 发送类文本恢复**逐次确认**（符合红线）；
- `02-config.js`：`TOOL_DOC.press_key` 更新说明。

### I-059 任务模式「自己骗自己」，中断后不肯续跑

主因与 I-057 同源：一次 400 后工具被永久关闭，提示词却仍在列工具，模型只能「演」出调用。QQ「打开→联系人→发消息」中断后重试最明显。

修改 `03-state-tasks.js`：

- 手机行为行补「要发送聊天消息时，输入完后用 press_key enter 提交，不要点被键盘挡住的按钮。只回话不调用工具等于没执行。」；
- 设备任务提示词从 6 条扩到 8 条，新增发送方式与「只回话而没有调用工具等于什么都没做；中断后先 read_screen 读真实页面再继续，不许假装已经完成」；
- 对 device / workspace / external 任务动态补一条续跑规则。
