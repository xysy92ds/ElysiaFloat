# 0.12.5 顶栏/输入区留白、用途绑定反馈、模型配置快捷化

时间：2026-10-28
触发：真机复测反馈（用途绑定点击无反馈、拖动范围小、输入框外留白大、设置底部条偏大）+ 模型配置快捷化需求

## 现象与修改

1. 用途绑定点了图标不变
   - `bindPurposeChange` 立即更新当前分组的 `.on`，不再等整页重绘；重绘时选中项加 `✓` 前缀，颜色 + 文字双反馈。
2. 拖动范围只有头像和名字
   - 拖动本来绑在 `#head`，但第二行几乎全是按钮。补齐 `#head .head-main/.head-actions` 的 `touch-action:none` 与 `user-select:none`；排除条件扩到 `button/input/textarea/select/a/label/[contenteditable]`，其余深粉区域都可拖，按钮点击不受影响。
3. 输入框外留白与底部空白
   - `#foot` padding 8/10 → 6/8，底部 10 → 8；`#input` padding 10/16 → 9/14、圆角 18 → 16；`#btn-plus`/`#send` 38/60 → 36/56。`#btn-plus` 补 `z-index:80`，低部留白收紧后仍不会被 `.rz` 缩放热区抢点击。
4. 设置底部保存条
   - `.settings-bottom` top padding 8 → 6、margin-top 12 → 8（bottom 保持 24 以满足 smoke 的 22px 热区约束）；`#settings-bottom-spacer` 96 → 64。
5. Provider 表单快捷配置
   - 新增「检测模型」：用当前地址 + Key 调 `/models`，返回的每个模型 chip 标注推断能力（对话/识图/生图/向量/语音/代码/搜索…），点选即写入默认模型。
   - 快捷服务商从 12 扩到 21（新增 xAI、Mistral、百度千帆、讯飞星火、腾讯混元、MiniMax、阶跃星辰、Together、302.AI、LM Studio）。
6. 识图 / 向量配置快捷选择
   - 从模型提供商中筛选带 `vision` / `embedding` 能力的 Provider，chip 点击后回填地址、模型与 Key；从提供商页返回设置时自动刷新。
7. 删除 EveryAPI 残留
   - 删除 `PRESETS.everyapi`、`DC.apiBase` 默认中转地址与 `gpt-5.6-luna` 默认模型，默认改为空地址 / `gpt-4o-mini`。
8. 剪贴板读取兜底
   - 原生桥 `Android.getClipboard` 读不到时，再尝试 `navigator.clipboard.readText()`（用户点击手势内），仍失败才提示；粘贴流程抽成 `fillPastedValue()`。
