日期：2026-10-16

## 本轮修复

### QuickOperation

- 翻译、总结、要点、解释改用临时 `QuickOperation`；
- 不再把这些操作加入持久任务舱；
- 输入框直接发送“总结屏幕/翻译屏幕/要点/解释”时，会进入对应快捷流程，而不是创建长期任务。

### 普通一次性读屏

- `PermissionBridge` 增加 `getScreenTextOnce()`；
- `PermissionBridge` 增加 `getScreenNodesOnce()`；
- 快捷屏幕功能只要求无障碍，不再要求 Agent 总开关；
- 屏幕翻译优先使用一次性节点读取接口；
- 持续手机 Agent 的 `read_screen` 仍保留原 Agent L1 门禁。

### 任务上下文

- 非聊天任务保存时不再写入 legacy `via_ai_history`；
- 当前任务清空使用当前任务历史键；
- 记忆总结清空流程改为调用当前任务清空；
- 导入历史配置后写入当前任务上下文。

### 更多菜单和清空

- 更多菜单固定背景、文字颜色和层级；
- 增加点击外部关闭；
- 清空入口在更多菜单中可见；
- 清空操作只清当前任务上下文。

### 设置分区

- 外观和自定义聊天人设移动到“个性化与聊天风格”区域；
- 删除旧的错误归属，避免被“屏幕翻译”折叠区隐藏；
- 设置分区默认全部收起，符合用户“不默认展开”的要求。

### 任务删除

- 增加长按/右键删除任务；
- 工作任务删除时先删除记录，再单独询问是否删除工作区文件；
- 主聊天不能删除，只能清空上下文；
- 增加删除按钮作为长按之外的备用入口。
