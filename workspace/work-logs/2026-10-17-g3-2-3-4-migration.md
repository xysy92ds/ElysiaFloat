## G3-2：插件 + 音乐

### 插件 HTTP

`11-plugin-engine.js` 两处（工具执行、沙箱 `host.request`）改为 `reqRequest`：

- `source: 'plugin:<id>'`，便于来源健康与审计归类；
- 保留插件自带 `timeout` 声明（夹在 1s~60s）；
- 沙箱宿主调用限制 `maxBytes: 800000`，返回仍截断到 200000 字符；
- 失败时把 RequestManager 的归一错误码透传出去
  （原来是 `plugFailure('NETWORK_ERROR', …)`，现在 `plugFailure(e.code || 'NETWORK_ERROR', …)`）。

### 音乐

`musicRequest` 迁入 `reqRequest`：

- `source: 'music:<source>'`，直接复用已有 `MUSIC_HEALTH` 记录成功/失败；
- **重试 1 次**（不是 2 次）：搜索速度优先，失效来源不该把首屏拖长；
- `maxRedirect: 5`，音乐 CDN 302 属正常业务，始终允许跨域。

### 跨域跳转策略（按用户决定）

新增 `reqSameHostOnly(source)`：

| 来源 | 跨域跳转 |
|---|---|
| `music:*` | 始终允许（CDN 302） |
| `system:*`（更新/翻译/记忆/TTS/市场） | 始终允许 |
| `plugin:*` / `agent*` | 受 **Agent L2** 控制：L2 关闭 → 只允许同域 |

实现方式：原生 `requestEx` 接收 `sameHost`，逐跳比较 host，不同则返回
`REDIRECT_ERROR`「跨域跳转被拒绝（Agent L2 未开启）」。

> 踩坑记录：最初用 `agentActionsOn()` 当判据，那是 L3 动作开关，
> 会导致 L2 开着也禁止跨域、并误伤普通插件。测试直接抓到了，已改为 `CONFIG.agentL2`。

### 短时签名直链不落盘

新增 `musicStripVolatile(song)`，剔除
`playUrl / play_url / play_urls / url / urls / media_url / mediaUrl / audio / src / expiresAt / expires_at`。

应用于四处持久化：播放历史、播放队列、缓存索引、收藏。
封面 `coverUrl` 与身份字段（id/source/name/artist）保留。
