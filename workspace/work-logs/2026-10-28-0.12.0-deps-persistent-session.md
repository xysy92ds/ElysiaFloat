### E5 依赖声明 / 检测 / 安装 / 卸载

- 清单层（`04-plugins-core.js`）：`PLUG_DEP_KINDS` 五类；下载类（archive/binary/apk）
  必须 HTTPS + 64 位 SHA-256，否则整条依赖判为无效；体积上限 200MB。
- 运行时层（`04c-plugin-deps.js`）：状态、计划、缺失、单项/全部安装、单项/全部卸载（逆序）、
  校验、面板、UI 事件、日志；`dependencies.manage` 权限校验。
- 原生层（`DependencyRuntime.kt`）：
  - 只允许 HTTPS，手动跟随最多 5 次跳转且每跳重新校验；
  - 流式下载 + 流式 SHA-256，超 200MB 立即中止；校验失败删除临时文件；
  - ZIP 解压做 canonical 路径防穿越；binary 安装后 `setExecutable`；
  - APK 只落 `cache/updates` 并交给系统安装器（`installApk`），应用内不静默安装；
  - lockfile 原子写（tmp + rename），记录 kind/version/sha256/size/path/installedAt；
  - 审计 `plugin-deps/audit.log`（超 200KB 截半）。
- Termux/npm 安装：固定模板执行 → 轮询状态（1200ms）→ 超时自动 `cancelTermuxJob`
  → 成功后 `recordDependency` 写 lockfile。
- 依赖面板：缺什么、类型、来源、体积、许可证、用途、进度与安装日志；设置页插件卡片与
  插件页 `deps` 模式共用。

- 保活引导：`persistKeepAliveGuideHtml` 写入更新的高级运行时区块；

- 运行状态条追加持久会话分钟数与预算已满提示；`updateRunStatus` 每秒驱动心跳。
