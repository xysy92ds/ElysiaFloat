# 0.12.3 设置折叠恢复 / 去掉重复状态 / 修复模型绑定点不动

时间：2026-10-28
触发：用户真机反馈（设置折叠丢失、运行秒数重复、模型绑定下拉箭头点不动、供应商类型下拉同样点不动）

## 现象与根因

1. 设置分区折叠丢失：0.7.2 的 `organizeSettingsSections()` 本来是「每节可点开/收起」，0.9 的 E1-004 把它替换成五个页签，0.12.2 删除页签时把折叠一起删掉了。
2. 运行状态条重复：0.9 新增的状态条显示「运行中 XXs」，而输入框上方本来就有「第 N 轮 / 已调用 M 次」的小字；停止键也与发送键的「停止」重复。
3. 模型提供商「自动选择」旁的箭头点不动：用途绑定和 Provider 类型用了原生 `<select>`，项目自己在 CSS 里注明「浮窗 WebView 里原生 select 点不动，要用分段按钮」。

## 修改

- `src/scripts/14-update.js`
  - 恢复 `organizeSettingsSections()`：每节一个可折叠标题，箭头 ▾/▸；展开状态持久化到 `via_ai_settings_folds`，下次打开保持上次状态；默认展开 AI 与模型、个性化、聊天与助手。
  - 用途绑定从 `<select>` 改为 `.chips` 按钮（自动选择 + 各 Provider），点击即绑定。
  - Provider 类型从 `<select>` 改为 chips，隐藏 input 承接值。
  - 新增 `settingsFoldState/IsOpen/Set`、`provKindSync`、`bindPurposeChange`。
- `src/template.html`：删除状态条里的独立「停止」键；新增输入框下方 `#run-sec` 显示执行秒数。
- `src/scripts/15-views.js`：状态条不再显示秒数，也不再有独立停止逻辑；秒数写到 `#run-sec`。
- `src/styles/main.css`：恢复 `.set-overview/.set-fold` 折叠样式与箭头；新增 `#run-sec`；#foot/#input 回退到 0.7.2 原样（去掉 0.12.2 的 min-height/align-items 改动）。
- `tools/smoke.js`：用例更新为折叠 + 箭头 + 持久化、无原生 select、秒数在输入框下方、停止由发送键切换。
