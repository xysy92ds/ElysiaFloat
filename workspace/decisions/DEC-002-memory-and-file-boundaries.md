# DEC-002：记忆新增策略和文件访问边界

日期：2026-10-06
状态：用户已确认并已实现第一版

## 记忆

- 总结任务以新增记忆为默认行为。
- 类别相同不代表是同一条记忆；同一类别可以有多条记录。
- 只有正文高度相似且明确属于同一事实时才合并。
- 合并必须保留原有正文，在末尾追加新内容，不得缩短原文。
- 明确修订原文时才使用覆盖式更新。

## 文件

- 工作区是 Agent 的默认受控写入范围：`Documents/ElysiaFloat/workspace`。
- 工作区外公共存储允许在用户授权和 Agent 安全条件满足时读取、写入、复制、创建目录和删除。
- 每次文件写入、覆盖、复制、创建目录和删除前都必须弹窗确认；确认只对本次操作有效。
- 路径仍限制在公共存储根目录内，工作区外权限不等于任意 Android 私有目录访问。
- “允许管理所有文件”是 Android 系统权限，不等于模型获得任意文件操作能力。
