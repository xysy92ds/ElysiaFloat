## 状态定义

- `未开始`：尚无实现；
- `基础骨架`：有数据结构、接口或局部实现，但不能宣称完整；
- `进行中`：已开始修复，仍存在已知缺陷；
- `真机待验`：代码完成但没有设备证据；
- `完成`：代码、自动测试和关键真机路径均通过；
- `暂缓`：等待用户指令或前置条件。

## 不允许混淆的语义

- `ChatSession`：普通聊天上下文；
- `QuickOperation`：一次性短操作，不默认持久化；
- `AgentTask`：手机、工作或外部 Agent 的持久任务；
- `clear current context`：只清当前任务上下文；
- `clear all contexts`：清全部任务对话，但不自动删文件；
- `clear all data`：高级危险操作，清配置、任务、记忆、收藏和聊天；
- 屏幕翻译默认是 `QuickOperation`，不是 `AgentTask`；
- 全屏 Activity 和 Overlay 悬浮窗是两个不同运行容器；
- 音乐缓存下载地址和音乐播放地址不是同一层，必须经过统一下载解析器。
