# 常见问题

## 安装与升级

### 安装时提示「签名不一致 / 应用未安装」

- 0.7.x 各版本使用同一把项目签名，可以直接覆盖安装；
- 从 0.6.x 或更早版本升级时，旧版签名不同，需要先卸载旧版再安装；
- 卸载会清除应用内数据，请先在「设置 → 数据管理」导出需要保留的配置与记录。

### 提示「禁止安装未知应用」

在系统设置中允许当前浏览器或文件管理器安装应用，然后重新打开 APK。

### 应用内更新下载失败

应用内更新从 GitHub Release 下载 APK。网络受限时可能失败，可打开 [Releases](https://github.com/xysy92ds/ElysiaFloat/releases) 手动下载，并核对 `SHA256SUMS`。

## 模型与聊天

### 发送消息后没有回复

按顺序检查：

1. 「设置 → AI 与模型」中的 API 地址、API Key 与模型名；
2. 该服务商是否兼容 OpenAI Chat Completions 接口；
3. 模型名是否真实存在（可用「检测」按钮读取 `/models`）；
4. 网络是否能访问该地址。

### 提示模型超时

生图、长推理或长文档处理可能超过默认超时。可在「设置 → Agent 与工作台 → 模型单次超时」中适当调大，执行过程中也可以随时停止。

### 聊天记录会保存在哪里

保存在设备本地应用私有目录。卸载应用会清除；可在「设置 → 数据管理」导出备份（导出内容不包含 API Key 与本地头像）。

## 手机 Agent

### Agent 无法启动或操作应用

确认以下条件同时满足：

- Agent 总开关已开启；
- 对应的 L1 / L2 / L3 已开启，L3 还需要开启安全开关；
- 无障碍服务已连接；
- 目标应用已加入应用白名单；
- 目标应用与查询结果中的包名一致（注意重名应用）；
- 当前任务授权未超过 30 分钟。

### 为什么每次操作都会弹确认

只有进入工作区或手机任务时的授权会复用 30 分钟。密码、支付、卸载、发送消息与删除文件不属于可复用授权，始终逐次确认。

### 读不到某些应用的界面

部分应用会限制无障碍节点读取，或使用自绘控件、`FLAG_SECURE`。这类界面只能尝试截屏，无法保证读取成功。

### 输入文字没有反应

先确认输入框已获得焦点；部分输入框不支持无障碍设置文本。应用不会自动切换系统默认输入法。

## 文件与工作区

### 找不到工作区

工作区固定位于：

```text
Documents/ElysiaFloat/workspace
```

需要先授予「允许管理所有文件」，再在设置中点击「创建工作区」。

### 工作区文件在卸载后会丢失吗

不会。工作区位于公共存储，卸载应用不会删除，需要时请手动清理。

### 覆盖写入会丢失原文件吗

覆盖前会在 `snapshots/` 生成快照，可在工作区面板中查看并回滚。

### 为什么删除文件总是要确认

删除不可逆，因此不参与任务授权复用，始终逐次确认。

## 插件

### 安装插件后看不到工具

安装、启用、授权是三个独立步骤。安装后需要在插件页启用并确认权限，工具才会出现在模型的工具列表中。

### 插件请求失败

按照错误码排查：

- `PERMISSION_DENIED`：插件或工具权限未授权；
- `NETWORK_PERMISSION_DENIED`：未声明网络权限，或局域网请求未开启安全开关；
- `INVALID_URL`：地址不合法或不是 HTTP(S)；
- `HTTP_ERROR`：目标服务返回异常状态码；
- `PLUGIN_RUNTIME_ERROR`：插件代码异常或超时。

### 插件能绕过 Agent 白名单吗

不能。插件权限只是声明，设备操作仍要经过 Agent 等级、安全开关、应用白名单与原生策略校验。

### 插件市场安全吗

市场索引只提供来源与完整性信息，不构成安全保证。安装前请阅读插件的 `README.md` 与权限列表，不要向插件提供密码、API Key 或 Cookie。

## 悬浮窗

### 悬浮窗不见了

检查是否授予了「显示在其他应用上层」与通知权限；也可以在应用内重新打开悬浮窗。

### 横屏时悬浮窗位置或大小异常

0.7.0 起窗口会按屏幕短边/长边保持宽高比并限制在屏幕内。若仍有异常，请附上设备型号、Android 版本与复现步骤提交 Issue。

## 隐私

### 应用会上传我的数据吗

除你配置的 AI 服务商、插件与音乐源外，应用不会主动上传内容。API Key、聊天记录、长期记忆与任务记录保存在设备本地。

### 屏幕内容会被当作指令执行吗

不会。屏幕文字、网页内容与文件内容都视为不可信数据，只作为上下文，不作为系统指令。
