# 权限与策略模型

## 1. 策略层级

Agent 能力分为三个等级：

- **L1**：读取目标应用的无障碍节点、文本和浏览器地址。
- **L2**：获取目标应用所在屏幕的图像。
- **L3**：执行点击、滑动、输入、系统按键和应用启动。

所有等级均受到 Agent 总开关控制。L3 额外要求安全开关。

## 2. 应用白名单

白名单存储在原生独立配置中，使用目标应用包名作为键。前端、提示词和模型不能替代原生策略校验。

应用名解析过程如下：

```text
显示名称或包名
    -> PackageManager 查询
    -> 唯一可启动应用
    -> 真实包名
    -> AgentPolicy 白名单校验
    -> 执行
```

名称解析成功不代表操作获准。未加入白名单的应用仍会被拒绝。

## 3. 文件权限模型

Android“允许管理所有文件”只表示系统允许应用访问公共存储，不能单独授予模型任意文件操作能力。

ElysiaFloat 进一步施加以下边界：

- 工作区是 Agent 的受控写入范围；
- 公共存储工作区外允许受控读取和修改；
- 工作区和工作区外的每次写入、复制、建目录、删除都必须经过前端逐次确认；
- 工作区写入和公共存储路径都必须经过 canonical path 校验；
- 拒绝路径穿越和公共存储根目录外路径；
- 文件 Agent 工具要求 L3 和安全开关；
- 覆盖文件在前端要求用户确认；
- 公共存储删除接口仅在用户逐次确认后执行；
- 插件能力声明不能绕过上述确认或 Android/Agent 原生策略。

## 4. 输入法权限

输入法服务属于 Android 系统输入法组件。ElysiaFloat 不在没有 Shizuku/root 的情况下修改默认输入法设置。用户必须显式启用并切换该输入法。

## 5. 截图和观察

屏幕截图由无障碍截屏或 MediaProjection 兜底实现。截图和限时观察前，悬浮窗会收起或临时隐藏，以减少目标画面遮挡。`watch_screen` 具有时长、采样频率和帧数限制，不提供后台无限观察。

## 6. 插件和市场

插件权限遵循“声明—授权—执行校验”模型。插件可以声明危险能力，但不能自行授予能力。启用插件时用户需要看到权限风险；工具调用时还会重新检查插件状态、权限、Android 条件、Agent 策略、安全开关、白名单和文件逐次确认。

远程市场只在用户主动点击同步后获取公开 HTTPS 索引。索引和 Manifest 不得访问用户数据，安装前检查：

- HTTPS 公网地址；
- `indexVersion`、Manifest Schema 和工具名冲突；
- 插件 ID 与索引版本一致；
- SHA-256 内容完整性；
- 用户安装确认和危险权限授权。

哈希、信任标签或审核状态不等于安全保证。插件审计记录只保存插件 ID、工具名、来源和时间，不保存工具参数、文件正文、网络请求体或用户消息。
