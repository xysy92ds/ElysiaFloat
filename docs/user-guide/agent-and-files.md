# Agent 与文件访问配置

Agent 不是“让模型直接控制手机”的开关，而是一组由 WebView、无障碍服务、截图授权和原生 `AgentPolicy` 共同限制的工具。模型只有在对应工具实际出现在工具列表中时才能调用；前端开关、插件权限和提示词都不能绕过原生门禁。

## 1. Agent 能做什么

| 等级/条件 | 能力 | 需要开启 |
|---|---|---|
| Agent + L1 | 查询设备中的真实可启动应用、读取无障碍节点文字、读取浏览器地址 | Agent 总开关、L1、无障碍；应用查询还受白名单策略约束 |
| Agent + L2 | 截图、识别屏幕图像、限时观察屏幕 | Agent、L1、L2、无障碍或系统截屏授权；截图可能再次询问用户 |
| Agent + L3 + 安全开关 | 点击、按文字点击、滑动、输入、系统按键、启动应用 | Agent、L3、安全开关、无障碍；启动应用还必须通过白名单 |
| 文件 Agent | 工作区和公共存储的读取/修改 | Agent 等级、文件权限、工作区状态；所有修改仍逐次确认 |

典型工作流是：先 `find_app` 查询真实应用 → 读取页面确认状态 → 执行一个动作 → 再读取页面验证。Agent 不应该凭空猜包名、坐标或页面内容。

## 2. 启用 Agent

在设置中依次确认：

1. Agent 总开关；
2. L1：读取设备信息；
3. L2：查看屏幕画面（需要截图/识图时）；
4. L3：执行设备操作；
5. 安全开关（L3 行为还需要它）；
6. Android 无障碍服务；需要截图时再授予系统截屏权限。

L1 负责“看”和“查询”，不等于能点击。L2 负责画面，不等于自动执行操作。L3 涉及点击、滑动、输入、系统按键和启动应用；发送、删除、支付、密码等不可逆操作仍应由用户确认。

## 3. 配置应用白名单

白名单是 Agent 的**应用启动/操作边界**，使用 Android 包名作为稳定标识，保存在原生配置中，不由模型或插件决定。设置页显示：

- 应用显示名称；
- 应用包名；
- 加入或移除状态；
- 应用搜索结果。

推荐流程：

1. 打开设置中的 Agent 应用白名单；
2. 搜索应用名称（例如“浏览器”“QQ”）或包名；
3. 核对显示名称和包名，处理重名结果；
4. 点击加入白名单；
5. 再让 Agent 启动或操作该应用。

模型调用 `find_app` 只负责查询设备实际安装的应用和包名；查询成功**不代表已获准操作**。`launch_app` 会重新解析并通过白名单检查，未加入的应用会被原生拒绝。点击、滑动和输入也会受当前前台应用、L3、安全开关及原生策略限制；插件声明 `device.action` 同样不能绕过白名单。

如果启动失败，依次检查：Agent 总开关、L3、安全开关、无障碍服务、应用是否加入白名单、是否选择了正确的重名应用，以及目标应用是否允许无障碍操作。

## 3. 配置工作区

在“文件访问与工作区”中：

1. 开启“允许管理所有文件”；
2. 创建工作区；
3. 确认工作区状态为已创建。

工作区路径：

```text
Documents/ElysiaFloat/workspace
```

工作区内允许 Agent：

- 列出目录；
- 读取文本文件；
- 创建目录；
- 创建和修改文本文件。

覆盖已有文件需要确认。工作区外可以读取、写入、复制、创建目录和删除公共存储文件；但是每一次实际修改、复制目标、创建目录或删除操作前，都会单独弹窗请求用户确认。确认只对本次操作有效，不构成永久授权。

## 4. 访问和修改工作区外文件

在用户授予“允许管理所有文件”后，Agent 可访问公共存储中的指定目录或文件。

读取接口：

```text
external_file_list
external_file_read
```

修改接口：

```text
external_file_write
external_file_copy
external_file_mkdir
external_file_delete
```

修改接口不采用永久授权。即使 Agent 或插件已经开启文件权限，每次写入、覆盖、复制、创建目录和删除前仍会显示目标路径、操作类型和确认按钮。

不应向 Agent 或插件提供包含密钥、身份凭据或个人隐私的文件，除非用户明确需要读取并承担相应风险。

## 5. 输入法备用通道

输入文字时系统首先尝试无障碍 `ACTION_SET_TEXT`。如果目标应用不支持该操作：

1. 打开“配置输入法兜底”；
2. 在系统输入法设置中启用“爱莉希雅输入法”；
3. 需要输入时手动切换到该输入法；
4. 再次执行输入操作。

本版本不会自动修改系统默认输入法。输入法备用通道尚未完成全部真机验证。
