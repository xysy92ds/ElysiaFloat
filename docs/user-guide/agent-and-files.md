# Agent 与文件访问配置

## 1. 启用 Agent

在设置中依次确认：

1. Agent 总开关
2. L1：读取设备信息
3. L2：查看屏幕画面
4. L3：执行设备操作
5. 安全开关

L3 涉及点击、滑动、输入、系统按键和启动应用。涉及发送、删除、支付、密码等不可逆操作时，仍应由用户确认。

## 2. 配置应用白名单

应用白名单使用 Android 包名作为稳定标识。设置页显示：

- 应用显示名称
- 应用包名
- 加入或移除状态

也可以搜索应用名称或包名。AI 启动应用前应先使用应用查询工具获取当前设备的真实包名；解析结果不会绕过白名单。

## 3. 配置工作区

在“文件访问与工作区”中：

1. 开启“允许管理所有文件”；
2. 创建工作区；
3. 确认工作区状态为已创建。

工作区路径：

```text
Documents/ElysiaFloat/workspace
```

工作区内允许 Agent：

- 列出目录；
- 读取文本文件；
- 创建目录；
- 创建和修改文本文件。

覆盖已有文件需要确认。工作区外可以读取、写入、复制、创建目录和删除公共存储文件；但是每一次实际修改、复制目标、创建目录或删除操作前，都会单独弹窗请求用户确认。确认只对本次操作有效，不构成永久授权。

## 4. 访问和修改工作区外文件

在用户授予“允许管理所有文件”后，Agent 可访问公共存储中的指定目录或文件。

读取接口：

```text
external_file_list
external_file_read
```

修改接口：

```text
external_file_write
external_file_copy
external_file_mkdir
external_file_delete
```

修改接口不采用永久授权。即使 Agent 或插件已经开启文件权限，每次写入、覆盖、复制、创建目录和删除前仍会显示目标路径、操作类型和确认按钮。

不应向 Agent 或插件提供包含密钥、身份凭据或个人隐私的文件，除非用户明确需要读取并承担相应风险。

## 5. 输入法备用通道

输入文字时系统首先尝试无障碍 `ACTION_SET_TEXT`。如果目标应用不支持该操作：

1. 打开“配置输入法兜底”；
2. 在系统输入法设置中启用“爱莉希雅输入法”；
3. 需要输入时手动切换到该输入法；
4. 再次执行输入操作。

本版本不会自动修改系统默认输入法。输入法备用通道尚未完成全部真机验证。
