# 上手教程（0.6.5）

这份教程按「装好 → 能用 → 会用它干活」的顺序走，跟着做就行。
每一步都写了「做完应该看到什么」，不对就停下来检查那一步。

---

## 第 0 步：了解它是什么

一个常驻在屏幕上的悬浮窗助手。它不只是聊天：

- **陪聊**：有固定人设的对话；
- **看屏幕**：读当前页面、截图、翻译、总结；
- **做任务**：在你自己开的权限范围内操作手机、整理文件、产出文档；
- **记事**：长期记忆库，越用越懂你；
- **放歌**：搜索、播放、缓存。

---

## 第 1 步：安装并打开

1. 安装 `ElysiaFloat-v0.6.5-debug.apk`（Debug 测试包，安装时可能提示"未知来源"，允许即可）；
2. 打开 App，会出现一个粉色悬浮窗。

> 装完看不到浮窗：回到桌面看一眼，它可能贴在边缘只露出小球。

---

## 第 2 步：开权限（缺一不可）

第一次打开会有一个权限引导页，按顺序点。如果漏了，去设置里补：

| 权限 | 用来做什么 | 不开会怎样 |
|---|---|---|
| **悬浮窗** | 显示助手界面 | 看不到任何界面 |
| **通知** | 保持前台服务不被系统回收 | 息屏后浮窗消失 |
| **电池优化白名单** | 同上 | 用一会儿就被杀 |
| **无障碍服务** | 读屏、点按、输入 | 不能看屏幕内容，不能操作手机 |
| **所有文件访问** | 读写工作区与公共存储 | 不能读文件、不能导出 |
| **屏幕截图/录屏** | 截图与观察画面 | 不能截图、不能看图 |

**检查方法**：设置页顶部会显示各项状态，全绿才算配齐。

---

## 第 3 步：配置模型

设置 → **AI 与模型**：

1. 选一个服务商预设，或手动填 **API 地址**（一般以 `/v1` 结尾）；
2. 填 **API Key**（旁边有「粘贴」按钮，直接读剪贴板）；
3. 点 **检测** —— 会拉取这个 Key 能用的模型列表，点一个填入；
4. 需要看图就再配一下「识图模型」（可留空，留空则只看文字）；
5. 点 **保存设置**。

**做完应该看到**：发一句「你好」，她会回你。

> 报错怎么办：错误提示后面带小字错误码。
> `401 / AUTH_ERROR` 是 Key 或地址不对；`429 / RATE_LIMITED` 是请求太快；`TIMEOUT` 是网络或服务慢。

---

## 第 4 步：四个典型用法

### 用法一：日常对话

直接在输入框说话。她会：
- 记住值得长期保留的信息（偏好、项目、约定）；
- 你问「你记得我什么」时，从记忆库检索后回答；
- 聊到一定消息量会自动整理记忆，你也可以在「更多 → 总结记忆」手动触发。

**试试**：先跟她说一件你正在做的事，过几轮再问「你还记得我在做什么吗」。

### 用法二：看屏幕

- 「帮我总结屏幕上写的是什么」；
- 「翻译一下这个页面」；
- 「这张图里有什么」（需要识图模型）。

结果会以胶囊形式收起来，点开看详情。

### 用法三：让它在手机上做事

说一句带动作意图的话，例如「打开微信，找到文件传输助手，发一句测试」。
它会先请你确认进入**手机控制模式**，然后：

1. 先读屏看当前是什么页面；
2. 一步一步操作（点击用页面上的位置，不靠猜坐标）；
3. 每做一步自动确认页面有没有变化，没变化会警告，连续无效会**暂停**等你；
4. 遇到密码框会先问你；
5. 切到白名单外的应用会立刻停止。

**关键设置**（设置 → Agent 与工作台）：

- 打开 Agent 总开关；
- **L1**：允许读屏；
- **L2**：允许在允许范围内执行；
- **L3 + 安全开关**：允许真正操作手机与写工作区外的文件；
- **应用白名单**：只有里面的应用能被操作，否则一律拒绝；
- **动作预算**：默认每次任务 120 步，用完是暂停，不是失败。

**做完应该看到**：任务舱里有一条动作流水，能看到每一步做了什么、页面有没有变化。

### 用法四：让它做一份文件

说「把刚才聊的内容整理成一份 Markdown 报告」，它会：

1. 进入工作任务（第一次会问你确认，之后同一任务里继续说不必重复确认）；
2. 在工作区里读写文件，**工作区内不需要逐次确认**；
3. 导出到 `output/`，聊天里出现一张小卡片，点「预览」直接看；
4. 结束时按「完成情况 / 产物路径 / 关键变化 / 未完成项」汇报。

**还能做什么**：

| 你说 | 它做 |
|---|---|
| 把这份 docx 里的要点列出来 | 解析 Word 正文再总结 |
| 这个 PDF 讲了什么 | 解析 PDF（扫描件会告诉你读不出、需要识图） |
| 把这个表格整理成 csv | 解析 Excel / 直接生成 csv |
| 把结果导成网页 | 生成 HTML 并自动补好外壳 |

> 任务完成后想回到聊天：点顶栏那个模式文字（显示「工作任务」「手机控制」的位置）。

## 第 5 步：几个提高效率的习惯

- **长按复制**：长按消息可以复制这条或选中一段；长按输入框可以粘贴；
- **附件**：输入框旁边的按钮可以发图片和文件，图片交给识图模型，文件会先解析成正文；
- **插件**：设置 → 插件页可以逐组、逐项开关工具，也能导入自定义插件；
- **音乐**：点音乐按钮进入，搜索支持多来源，长按歌曲可以收藏、缓存、删除记录；
- **主题**：设置里改主题色，音乐页与工作区界面会一起跟着变。

---

## 第 6 步：安全建议

1. 白名单只放你真的允许它操作的应用，不要长期开「允许所有应用」；
2. 外部存储的写入与删除每次都会确认——看清路径再点允许；
3. 不用的时候把 Agent 总开关关掉；
4. API Key 只存在本机，导出配置时注意别把 Key 一起发出去；
5. 屏幕内容（聊天、验证码、转账页）属于隐私，截图前想一下。

## 常见问题

**Q：为什么它不肯操作某个应用？**
A：三种可能：Agent 没开、L3 或安全开关没开、那个应用不在白名单。任务舱里会写明拒绝原因。

**Q：为什么任务做到一半停了？**
A：多半是动作预算用完或连续几步页面没变化——这是保护，不是失败。说「继续」会再给一批预算。

**Q：为什么 PDF 说读不出文字？**
A：那是扫描件（图片版），没有文字层。可以截图给它，用识图去看。

**Q：模型一直转圈 / 超时？**
A：生图和长推理会比较慢，默认给了 600 秒；仍可随时点停止。想更久可以在设置里调「模型单次超时」。

**Q：换了服务商要重配吗？**
A：改地址和 Key 后点「检测」，从列表里挑模型再保存即可。

---

## 出问题了怎么反馈

在设置里导出配置（会自动隐去 Key），加上：
- 你做了什么、期望什么、实际看到什么；
- 任务舱里的动作流水（如果和手机操作有关）；
- 错误提示里的错误码。
