# 手机 Agent 使用说明

Agent 不是「让模型直接控制手机」的总开关，而是一组由 WebView、无障碍服务、截图授权和原生 `AgentPolicy` 共同限制的工具。模型只有在工具实际出现在工具列表中时才能调用；前端开关、插件权限和提示词都不能绕过原生校验。

## 1. 开启步骤

在「设置 → Agent」中依次确认：

1. Agent 总开关；
2. L1：读取设备信息（查询应用、读取界面文字与浏览器地址）；
3. L2：查看屏幕画面（截屏、识屏、限时观察）；
4. L3：执行设备操作（点击、滑动、输入、按键、启动应用）；
5. 安全开关（L3 行为必须同时开启）；
6. Android 无障碍服务；需要截屏时再授予系统截屏权限。

首次进入手机任务时，应用会请求一次任务授权，30 分钟内同任务内的设备操作不再重复询问。任务结束、删除或应用重启后需要重新授权。

## 2. 配置应用白名单

白名单是 Agent 的启动与操作边界，以 Android 包名为键，保存在原生配置中：

1. 打开「设置 → Agent → 应用白名单」；
2. 搜索应用名称或包名；
3. 核对显示名称与包名，处理重名结果；
4. 加入白名单；
5. 再让 Agent 启动或操作该应用。

`find_app` 只负责查询设备上真实安装的应用；查询成功不代表已获准操作。未加入白名单的应用会被原生拒绝。

## 3. 常用工具

| 工具 | 作用 | 等级 |
|---|---|---|
| `find_app` | 查询真实应用名与包名 | L1 |
| `read_screen` | 读取当前界面的节点文字与控件 | L1 |
| `get_current_page` | 获取当前页面信息（含浏览器地址） | L1 |
| `screenshot` | 截取当前屏幕 | L2 |
| `watch_screen` | 限时观察屏幕变化 | L2 |
| `click_text` | 按文字或描述点击控件 | L3 |
| `tap_screen` | 按比例坐标点击 | L3 |
| `swipe_screen` | 滑动或滚动 | L3 |
| `input_text` | 向焦点输入框输入文字 | L3 |
| `press_key` | 返回、主页、最近任务、通知栏 | L3 |
| `launch_app` | 启动白名单中的应用 | L3 |

推荐工作流：先 `find_app` 确认应用 → `launch_app` 打开 → `read_screen` 确认页面 → 执行一个动作 → 再次 `read_screen` 验证结果。Agent 不应猜测包名、坐标或页面内容。

## 4. 高风险操作

以下操作始终需要用户逐次确认，任务授权不会跳过：

- 密码输入与提交；
- 支付、转账；
- 卸载应用；
- 发送消息；
- 删除文件或目录。

## 5. 常见失败原因

| 现象 | 检查项 |
|---|---|
| 无法启动应用 | L3、安全开关、无障碍、应用是否在白名单、是否选对重名应用 |
| 读不到界面 | 目标应用是否限制无障碍、L1 是否开启、页面是否已加载完成 |
| 截图失败 | 系统截屏授权、L2、悬浮窗是否被目标应用遮挡 |
| 输入无反应 | 目标输入框是否支持无障碍设置文本、输入框是否已获得焦点 |
| 操作被拒绝 | 当前前台应用是否在白名单、是否超过任务授权时间 |

## 6. 提示

- 不要向 Agent 提供密钥、身份凭据或隐私文件，除非你明确需要并知晓风险；
- 屏幕内容与页面文字属于不可信数据，不会被当作指令执行；
- 长任务可随时停止，停止后不会再执行后续工具调用。
