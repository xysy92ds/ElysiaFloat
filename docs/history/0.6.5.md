# 0.6.5 —— 从悬浮窗助手到可执行任务的手机 Agent

> 一句话：这一版把「能聊天、能看屏幕」的浮窗助手，做成了「能接任务、能动手、能交付文件」的手机 Agent，
> 并为它配齐了统一的网络层、分层的提示词、以及一套收敛后的权限模型。

---

## 一、整体变化

### 1. Agent 真正能"做任务"了

过去 Agent 只能零散地调用工具；这一版建立了完整的执行闭环：

- **任务有生命周期**：聊天、快捷操作、手机任务、工作任务、外部任务各自独立，互不串线；
- **执行有阶段**：读取页面 → 规划 → 执行 → 验证 → 交付，非法跳转会被拒绝；
- **动作有验证**：每次点击/输入后自动比对页面是否变化，连续无效会暂停而不是继续盲操作；
- **预算可控**：动作数量与任务时长都可配置，用完是**暂停并等你决定**，不是失败；
- **随时可停**：停止会真正中断模型请求、插件调用与页面观察，迟到结果不会污染新任务。

### 2. 本地工作台成型

工作区不再只是一个文件抽屉，而是「任务的产出地」：

- **能读多种格式**：纯文本、Word、Excel、幻灯片、电子书、压缩包清单、PDF；
- **能产出多种格式**：Markdown、纯文本、CSV、JSON、HTML，统一落在 `output/`；
- **能快速预览**：导出后直接在聊天里点开查看，长文本可滚动、可复制；
- **写入更安全**：原子写入（不会留半截文件）、拒绝符号链接、递归删除有边界。

### 3. 网络层统一

所有出网请求（对话、识图、插件、音乐、更新、翻译、记忆检索）收敛到同一个请求管理：

- 统一超时与预算，长任务不再被固定秒数误杀；
- 统一错误码，失败原因可读（认证、限流、超时、内容过大、解析失败各有标识）；
- 统一脱敏审计，只记域名/状态码/耗时，不记地址参数与凭据；
- 跨域跳转策略可按能力级别控制，插件不能随意把请求带到任意主机。

### 4. 提示词分层：工作归工作，人设归人设

- 安全规则与输出纪律永远在最前，且不含人设；
- 执行任务时使用标准 Agent 工作协议（目标 → 计划 → 执行 → 验证 → 交付，完整性优先、最小改动、不编造、受阻就停）；
- 人设只作用于**对话语气**与**任务完成后的汇报措辞**，不再影响判断与执行；
- 工具调用不会再以 JSON 或伪代码的形式漏进聊天正文。

### 5. 权限模型收敛

- 手机与文件能力统一到 **L1 / L2 / L3 + 安全开关 + 应用白名单**这一套，不再额外叠私有开关；
- 工作区（受控写入区）与工作区外（公共存储）分级：区内写入不需要逐次确认，区外仍然要；
- 高风险动作（密码框输入、外部写入与删除、Root 诊断）保留逐次确认。

### 6. 记忆与音乐成为完整子系统

- **记忆**：自动按消息量整理进记忆库，也支持手动触发；索引 + 检索 + 向量可选，重启不丢计数；
- **音乐**：多来源搜索与分页、播放/歌词/收藏/历史/队列/缓存面板、下载进度与单曲删除、随主题换色。

## 二、兼容与迁移

升级后**不需要重新配置**，以下几项会自动处理：

| 场景 | 处理方式 |
|---|---|
| 老配置里单次任务时长还是旧默认 | 自动迁移到新默认 |
| 历史上存在多个「主聊天」 | 自动合并为一个，消息保留 |
| 旧默认人设 | 自动升级到新默认；自己改过的不动 |
| 文件确认策略变化 | 工作区内免确认，工作区外保持确认 |

## 三、已知限制

- **全屏仍是"最大化悬浮窗"**：真正的独立全屏界面尚未实现，系统栏行为受厂商限制；
- **Termux / Root / 外部 Agent**：协议与门禁已就绪，但完整的执行、回传、取消与审计仍在后续版本；
- **PDF 文本提取**：仅支持有文字层的 PDF；扫描件会明确提示需要识图，而不是假装读出内容；
- **Excel / 幻灯片**：按纯文本抽取单元格与文本框，复杂公式、图表、样式不会保留；
- **公共音源**：可用性取决于第三方服务，短时签名地址不做长期缓存。
