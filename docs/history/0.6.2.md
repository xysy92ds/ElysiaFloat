# ElysiaFloat 0.6.2 版本历史

## 版本信息

- versionName：`0.6.2`
- versionCode：`12`
- 目标：完善插件宿主、远程只读市场同步和当前应用文档。

## 主要内容

- 插件危险权限在清单规整时不再默认授权；旧插件缺少授权状态时按未授权并停用处理；
- 增加插件状态、来源、信任标签、审核状态、安装时间、调用次数和最近调用记录；
- 增加插件安装、启用、停用、调用和卸载审计记录，记录不包含工具参数和用户数据；
- 增加统一错误码，包括权限拒绝、网络拒绝、HTTP 错误、沙箱错误和插件运行错误；
- 远程插件市场支持用户主动同步 HTTPS 只读索引；
- 远程插件安装前校验 Manifest、插件 ID/版本一致性和 SHA-256 内容完整性；
- 本地市场和远程市场在界面中区分来源、信任状态和审核状态；
- 更新当前应用文档，使当前状态说明与实现一致；
- 增加远程市场索引中的公开示例插件和 SHA-256 摘要；
- 应用版本提升为 `0.6.2` / versionCode `12`。

## 安全边界

远程索引不会自动安装插件或自动执行远程代码。哈希校验只证明下载内容与索引内容一致，不证明代码安全；签名根、撤销服务和人工审核责任边界仍需后续建立。插件危险权限、Android 权限、Agent 策略、白名单和文件逐次确认继续独立生效。
