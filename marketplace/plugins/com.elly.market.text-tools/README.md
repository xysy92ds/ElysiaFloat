# 文本处理示例插件

## 用途

该插件用于验证 ElysiaFloat 插件协议 v1。它只接收调用参数并返回文本统计结果，不访问网络、文件、设备、剪贴板、长期记忆或其它宿主能力。

## 权限

```json
"permissions": []
```

这是最小权限示例。插件仍在隔离沙箱中执行。

## 工具

### `text_inspect`

输入：

```json
{
  "text": "第一行\n\n第二行"
}
```

返回：

```json
{
  "characters": 8,
  "lines": 3,
  "nonEmptyLines": 2
}
```

错误情况：缺少 `text` 时按空文本处理；其它异常由宿主包装为工具错误。

## 开发流程

1. 复制此目录；
2. 修改 `id`、名称、版本和工具描述；
3. 为插件和每个工具声明最小 `permissions`；
4. 补充隐私说明、错误模型和测试步骤；
5. 在应用中通过“插件市场”或“导入插件”安装；
6. 检查权限展示后再启用。

## 安全限制

插件代码无法获得 `Android` 对象。需要文件、设备、网络或其它宿主能力时，必须在清单中声明对应权限，并通过 `host.callTool` 调用；宿主还会检查用户授权和系统策略。文件修改不会因为插件授权而跳过逐次确认。
