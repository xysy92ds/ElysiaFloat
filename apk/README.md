## 安装方法

1. 下载 APK 到手机
2. 点击安装，如果系统提示「未知来源」，去设置里允许一次
3. 首次打开会进入**权限引导页**，按顺序点完：
   - 悬浮窗权限（必须）
   - 通知权限（建议）
   - 无障碍服务（读屏 / 屏幕翻译要用，需在系统设置里手动开）
   - 电池优化白名单（防止浮窗被杀，建议）

> ⚠️ 如果之前装过旧版本，升级后建议把**无障碍服务关掉再打开一次**，让新的服务属性生效。

## 装完先做什么

1. 点悬浮球 → 设置 → 填 **API 地址** 和 **API Key**（任意 OpenAI 兼容接口），选一个模型，保存
2. 想要读屏 / 翻译屏幕：去系统设置里把「爱莉希雅」的无障碍服务打开
3. 想让她看图：设置里往下拉有「🖼️ 识图模型」区，填一个支持视觉的模型（如 `gpt-4o`、`qwen-vl-max`）
4. 想让她记事：底部 🧠 进去看看，可以先手动「＋ 新建」一条试试；也可以先聊几句，再让她自己整理
5. 想要屏幕翻译：快捷条点「翻译屏幕」，她会自己读屏并把窗口收成小胶囊，跑完点红点看结果
6. 想扩展能力：设置 → 插件与工具 → 导入插件，粘贴一段 JSON 清单即可；也可以在这里关掉不想让她用的工具

## 关于这个包

- **纯 Kotlin + Android Framework**，`dependencies {}` 是空的，没有任何第三方库
- **不含 native 库**，所以不挑 CPU 架构，一个包通吃
- 体积小（约 2 MB）、启动快，界面全部由一个本地 `index.html` 渲染

源码和架构说明见 [`../README.md`](../README.md)，插件开发见 [`../PLUGINS.md`](../PLUGINS.md)。

## 权限用途

| 权限 | 干什么用的 |
|---|---|
| 悬浮窗 | 显示悬浮球和聊天窗 |
| 前台服务 | 让浮窗常驻不被回收 |
| 通知 | 前台服务提示（Android 13+ 需要授权） |
| 网络 | 请求 AI / 音乐 / 翻译接口 |
| 无障碍 | 读其它 App 的界面文字和坐标、屏幕翻译 |
| 媒体投影 | 截屏（识图兜底、AI 的 screenshot 工具） |
| 安装未知应用 | 下载新版本后调起系统安装器 |
| 震动 | 操作反馈 |
