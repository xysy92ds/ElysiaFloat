# 📦 安装包

## ElysiaFloat-v7-debug.apk

| 项 | 值 |
|---|---|
| 包名 | `com.elly.assistant` |
| 版本 | 1.2（versionCode 3） |
| 最低系统 | Android 7.0（API 24） |
| 目标系统 | Android 14（API 34） |
| 构建类型 | debug（自用签名） |

## 安装方法

1. 下载 APK 到手机
2. 点击安装，如果系统提示「未知来源」，去设置里允许一次
3. 首次打开会进入**权限引导页**，按顺序点完：
   - 悬浮窗权限（必须）
   - 通知权限（建议）
   - 无障碍服务（读屏 / 截屏要用，需在系统设置里手动开）
   - 电池优化白名单（防止浮窗被杀，建议）

## 关于架构

这个 APK **不含任何原生 `.so` 库**，项目是纯 Kotlin + Android Framework 实现。

所以它是**全架构通用**的：`arm64-v8a` / `armeabi-v7a` / `x86` / `x86_64` 都能正常安装运行，不需要按 CPU 架构挑选。

## 装完先做什么

1. 点浮窗 → 设置 → 填 **API 地址** 和 **API Key**（任意 OpenAI 兼容接口）
2. 选一个模型，保存
3. 想要读屏 / 截图，去系统设置里把「爱莉希雅」的无障碍服务打开
   - ⚠️ 如果之前开过、后来升级了 APK，建议**关掉再打开一次**，让新属性生效
4. 想让她看图：设置里往下拉有「识图模型」区，填一个支持视觉的模型（如 `gpt-4o`、`qwen-vl-max`）

## 权限用途

| 权限 | 干什么用的 |
|---|---|
| 悬浮窗 | 显示悬浮球和聊天窗 |
| 前台服务 | 让浮窗常驻不被回收 |
| 通知 | 前台服务提示（Android 13+ 需要授权） |
| 网络 | 请求 AI / 音乐 / 翻译接口 |
| 无障碍 | 读其它 App 的文字、截屏、拿浏览器地址 |
| 震动 | 操作反馈 |
